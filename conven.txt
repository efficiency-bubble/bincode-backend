Node type conventions (subject to change):
0 = uint32($0)
1 = uint64($0)
2 = pack(node($)...)
3 = (... , node($))[$0]
4 = node($)[$0], pack indexing
5 = arg
6 = *$0
7 = &$0
9 = callf(node($0),...)
10 = setvar(uint64($0),node($1))
11 = getvar(uint64($0))
12 = havevar(uint64($0),node($1),node($2)) # returns { let var$0 = $1 in $2 }
20 = bool($0)
21 = (bool($0) ? node($1) : node($2))
30 = sint32($0)
100 = uint32(SYMTAB[$0]) # TODO: check symbol table to automatically determine value width
101 = uint64(SYMTAB[$0])
200 = FN[$0]
201 = callf(OS[$0],...)
254 = (( extern stub )) # as a root node of a function, indicates that it is an imported function.

Additional DFG node types:
310 = sequence
400 = stdout begin

Intrinsics:
10 = add uint32
11 = add sint32

20 = sub uint32
21 = sub sint32

30 = mul uint32
31 = mul sint32

50 = uint32 == uint32
51 = uint32 <= uint32
60 = !bool
100 = print uint32
