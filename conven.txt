Node type conventions (subject to change):
0 = uint32($0)
1 = uint64($0)
2 = pack(node($)...)
3 = (... , node($))[$0]
4 = node($)[$0], pack indexing
5 = arg;
9 = callf(BUILTIN_FN[$0],node($1))
10 = setvar(uint64($0),node($1))
11 = getvar(uint64($0))
20 = bool($0)
21 = (bool($0) ? node($1) : node($2))
100 = uint32(SYMTAB[$0]) # TODO: check symbol table to automatically determine value width
101 = uint64(SYMTAB[$0])
200 = FN[$0]

Additional DFG node types:
300 = proxy (id)
301 = loopcontrol
400 = stdout begin

Built-in functions:
0 = call function
10 = add (AST) / add uint32 (DFG)
11 = add sint32 (DFG)

20 = sub (AST) / sub uint32 (DFG)
21 = sub sint32 (DFG)

30 = mul (AST) / mul uint32 (DFG)
31 = mul sint32 (DFG)

50 = uint32 == uint32
51 = uint32 <= uint32
60 = !bool
